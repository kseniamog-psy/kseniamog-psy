# Сайт-визитка психолога Ксении Могилевич

Статический сайт: `index.html` + папка `assets/` с картинками. Без сборки и зависимостей.

## Как выложить на GitHub Pages (получить живую ссылку)

1. На github.com нажмите **New repository**, назовите, например, `ksenia-psy` (репозиторий публичный).
2. Нажмите **uploading an existing file** и перетащите файлы: `index.html`, `privacy.html`, `consent.html`, `offer.html`, `legal.css`, `README.md` и папку `assets` целиком.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Deploy from a branch*, ветку `main`, папку `/ (root)`, сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ksenia-psy/`.

## Что нужно заполнить перед публикацией

1. **Контакты.** Telegram `kseniamog` и телефон +7 916 309-87-79 (WhatsApp и Max) уже вписаны в блок `CONTACTS` в конце `index.html` и в строку «Или напишите напрямую» под формой. Если контакты изменятся, поправьте оба места.
2. **Отзывы.** В блоке «Отзывы» три карточки с текстом `[Текст отзыва клиента]`. Замените на настоящие отзывы, только с согласия авторов и без деталей запроса.
3. **Реквизиты.** ИП и ИНН вписаны в подвал и документы. В `offer.html` осталось добавить ОГРНИП.
4. **Документы.** Страницы `privacy.html` (политика конфиденциальности), `consent.html` (согласие на обработку данных) и `offer.html` (договор-оферта) сделаны как шаблоны. Жёлтые отметки `[...]` нужно заполнить: адрес сайта, дата, ОГРНИП, порядок оплаты, условия отмены, платформа для онлайн-консультаций. Перед публикацией покажите документы юристу.

## Сертификаты в блоке «Обо мне»

Под каждым учебным заведением есть кнопка «Посмотреть сертификат». Сканы уже лежат в папке `assets/certs/`. Чтобы заменить один из них, положите файл с тем же именем (список в `assets/certs/README.txt`). Если файла нет, показывается надпись «Скан сертификата скоро появится здесь».

## Интерактив «Немного ближе к себе»

Вопросы лежат в массиве `QUESTIONS` в конце `index.html`. Сейчас там один вопрос; чтобы добавить второй и третий, скопируйте блок `{ title: ..., options: [...] }` через запятую.
